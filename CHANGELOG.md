# Changelog

All notable changes to this project are recorded in this file. The format is kept simple so that a reviewer can understand the development history.

## 1.0.0 — Initial lab project

### Added
- Created the CSE103 Lab 3 repository structure.
- Added `README.md` with the project overview, requirements, setup instructions, and lab-question coverage.
- Added `MARKDOWN_GUIDE.md` to demonstrate common Markdown syntax.
- Added `main.py` with a reusable greeting function and project information.
- Added `api_client.py` to request and process user data from JSONPlaceholder.
- Added `sample_users.json` as an illustrative JSON dataset.
- Added `tests/test_api_client.py` to test the user-summary function.
- Added `.gitignore` rules for Python cache files, virtual environments, environment files, and generated API output.

### Improved
- Added response validation and basic exception handling to the API client.
- Used readable function names and comments to make the examples easier to follow.
- Documented how to run the examples and unit test.

## Planned improvements
- Add more unit tests for invalid or incomplete API data.
- Add pagination or filtering examples if required by a future exercise.
- Expand the troubleshooting section based on errors encountered during practice.
